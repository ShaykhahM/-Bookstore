Bookstore
طريقة تشغيل المشروع
المتطلبات
يجب أن يكون Node.js مثبتًا على الجهاز.
التشغيل
قم بتحميل أو نسخ المشروع إلى جهازك.
افتح المشروع باستخدام Visual Studio Code.
افتح الـ Terminal داخل مجلد المشروع.
تأكد من وجود الملف:
books.js

شغّل البرنامج باستخدام الأمر:
node books.js

ستظهر نتائج البحث والإضافة والتعديل والحذف في الـ Terminal.
ملاحظة
يمكن تغيير رقم الـ ID أو اسم الكتاب أو اسم المؤلف داخل الكود لتجربة عمليات البحث المختلفة.
